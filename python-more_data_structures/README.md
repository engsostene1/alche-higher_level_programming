# Python - More Data Structures

A short project focusing on Python **sets**, **dictionaries**, and basic functional tools like **lambda**, **map**, **filter**, and **reduce**.

## Overview
Work includes:
- Using sets for unique items and comparisons  
- Using dictionaries for key/value operations  
- Applying functional programming tools  
- Writing clean Python code following pycodestyle

## Requirements
- Files start with `#!/usr/bin/python3`
- No imports allowed
- Must follow **pycodestyle 2.7**
- All files executable  
- Ubuntu 20.04, Python 3.8.5  
- README.md is mandatory

## Tasks Summary
- **0**: Square all numbers in a matrix  
- **1**: Replace element in list  
- **2**: Sum unique integers  
- **3**: Common elements in sets  
- **4**: Elements only in one set  
- **5**: Count dictionary keys  
- **6**: Print dictionary sorted by keys  
- **7**: Update/add dictionary key/value  
- **8**: Delete key if present  
- **9**: Multiply dictionary values by 2  
- **10**: Return key with highest score  
- **11**: Multiply list using `map`  
- **12**: Convert Roman numeral to integer  

## Goal
Practice Python’s core data structures and functional programming tools through small, focused exercises.
