# Python - Data Structures: Lists and Tuples

This project is my introduction to working with lists and tuples in Python.  
The tasks here focus on basic operations like accessing elements, printing values, slicing, replacing items, and understanding how Python handles mutable vs immutable types.

## What I learned
- How to work with Python lists
- How to access elements by index
- How to print integers using `str.format()`
- How to modify list values
- How tuples differ from lists
- How Python handles errors when types don't match

## Files in this directory

### 0-print_list_integer.py
Function that prints all integers in a list, one per line, using `{:d}.format()`.  
No imports, no casting allowed.

### 1-element_at.py
Returns an element from a list at a given index.  
Handles out‑of‑range indexes safely.

### 2-replace_in_list.py
Replaces an element at a specific position in a list.

### 3-print_reversed_list_integer.py
Prints all integers of a list in reverse order.

### 4-new_in_list.py
Creates a new list with one element replaced, without modifying the original.

### 5-no_c_in_string.py
Removes all characters `c` and `C` from a string.

### 6-print_matrix_integer.py
Prints a matrix of integers using proper formatting.

### 7-add_tuple.py
Adds two tuples element‑wise.

### 8-multiple_returns.py
Returns a tuple with the length of a string and its first character.

### 9-max_integer.py
Finds the biggest integer in a list.

### 10-divisible_by_2.py
Checks which numbers in a list are divisible by 2.

### 11-delete_at.py
Deletes an item at a specific position in a list.

### 12-switch.py
Switches the values of two variables.
